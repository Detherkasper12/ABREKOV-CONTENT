# ABREKOV Resources

Сайт с ресурсами для @abrekov.design: публичная библиотека на иврите (RTL) и закрытая админка `/admin`, где ресурсы создаются и редактируются блоками без кода и без редеплоя.

Стек: Next.js 16 (App Router, TypeScript), Tailwind CSS 4, Supabase (Postgres, Auth, Storage), Vercel.

## Как устроено

- Контент лежит в Postgres (Supabase). Публичные страницы рендерятся на каждый запрос, поэтому изменения в админке видны сразу.
- Сервер ходит в базу напрямую через `DATABASE_URL`. На всех таблицах включён RLS без политик, так что публичный anon-ключ не читает и не пишет ничего.
- Вход в админку через Supabase Auth (email + пароль). Доступ только у адресов из `ADMIN_EMAILS`. Каждая страница админки и каждое серверное действие проверяют пользователя на сервере.
- Картинки и бесплатные файлы грузятся из браузера прямо в публичный bucket `media` по одноразовой подписанной ссылке.
- Платные продукты: в базе только описание, превью, цена и ссылка на hosted checkout (например, Lemon Squeezy). Файлы платных продуктов отдаёт провайдер оплаты, на сайт они не загружаются. Платный ресурс нельзя опубликовать без цены и https-ссылки на checkout.
- Рассылка: double opt-in. Форма показывается, только если она включена в настройках и заданы `RESEND_API_KEY` и `NEWSLETTER_FROM_EMAIL`. Подтверждённых подписчиков можно скачать CSV в `/admin/subscribers`.

## Первый запуск в продакшене

1. **Supabase.** Создай проект на supabase.com.
   - SQL Editor → вставь `supabase/migrations/0001_init.sql` → Run.
   - SQL Editor → вставь `supabase/seed.sql` → Run (добавит «5 Claude Skills» и «CLAUDE.md»).
   - Authentication → Users → Add user → твой email и пароль.
   - Authentication → Sign In / Providers → выключи «Allow new users to sign up».
2. **Vercel.** Импортируй репозиторий, добавь переменные из `.env.example` (Settings → Environment Variables), задеплой.
3. Открой `https://твой-домен/admin`, войди.

## Локально

```bash
cp .env.example .env.local   # заполни
npm install
npm run dev
```

Без проекта Supabase можно гонять всё локально: локальный Postgres + `scripts/mock-supabase.mjs` (заглушка Auth и Storage только для разработки и тестов). Миграция: `psql $DATABASE_URL -f supabase/migrations/0001_init.sql`, контент: `node --env-file=.env.local scripts/seed.mjs --apply`.

Проверки:

```bash
npx tsc --noEmit
npm run lint
npm run build
node scripts/e2e-smoke.mjs   # сквозной тест в браузере против запущенного сервера (нужен Playwright)
```

## Как опубликовать следующий ресурс

1. `/admin` → «+ משאב חדש».
2. Заголовок, короткое описание, адрес страницы (например `figma-plugins`), категория, код поста (`DROP / 002`) и слово для комментария.
3. Блоки снизу: כותרת, טקסט, תמונה, קוד, פרומפט, קישור, קובץ, וידאו, קו מפריד, CTA. Стрелки ↑ ↓ меняют порядок, ⧉ дублирует, ✕ удаляет. В тексте работают `**жирный**`, `` `код` ``, `[ссылка](https://…)` и списки.
4. «שמירה» (или Ctrl/Cmd+S) → «תצוגה מקדימה» → «פרסם».
5. Ссылка `https://твой-домен/resources/<адрес>` идёт в авто-DM.

## Платный продукт

Создай ресурс, переключи «בתשלום», укажи цену в ₪ и ссылку на checkout из Lemon Squeezy (или другого провайдера). Блоки страницы — публичное превью. Пока нет одобренного магазина и ссылки, продукт остаётся черновиком и кнопки покупки нет.
